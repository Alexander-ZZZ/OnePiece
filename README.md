# 🏴‍☠️ One Piece: La Gran Era de los Piratas

Una experiencia web interactiva, moderna y deslumbrante ambientada en el legendario universo de **One Piece**, desarrollada con HTML5, CSS3 vanila de alto impacto (diseño pergamino y glassmorphism pirata) y JavaScript modular.

---

## 🌟 Características Principales

1. **Hero Section Inmersivo**:
   - Fondo panorámico navegante (`imagenes/img2.jpg`).
   - Partículas en movimiento en vivo (polvo marino y destellos dorados).
   - Brújula y contador dinámico de estadísticas de la Grand Line.

2. **Tripulación de Sombrero de Paja (Mugiwaras)**:
   - Tarjetas interactivas con recompensas oficiales (*Berries*).
   - Filtros de tripulación (Liderazgo, Navegación, Especialistas).
   - Fichas modales detalladas con habilidades, estadísticas de combate y frases célebres.

3. **Sección Gear 5: El Despertar del Dios del Sol Nika**:
   - Presentación visual con `imagenes/img1.jpg`.
   - Pestañas con la evolución de transformaciones (Gear 2, Gear 3, Gear 4 y Gear 5).
   - **Sintetizador Web Audio**: Botón interactivo para reproducir el ritmo de los **Tambores de la Liberación**.

4. **Hermandad y Voluntad de D. (ASL)**:
   - Presentación de la promesa entre Luffy, Ace y Sabo (`imagenes/img3.jpg`) en marco de pergamino envejecido.
   - Acordeones interactivos con el lore sobre los Poneglyphs, el Siglo Vacío y los Yonko.

5. **Enciclopedia de Frutas del Diablo (Akuma no Mi)**:
   - Buscador en tiempo real por nombre, habilidad o usuario.
   - Filtros por tipo de fruta (Paramecia, Zoan, Logia, Mitológica).

6. **Generador Interactivo de Carteles "WANTED"**:
   - Renderizado en vivo mediante **HTML5 Canvas**.
   - Configuración de nombre pirata, epíteto, monto de recompensa y fotos.
   - Botón para descargar el cartel generado en formato **PNG**.

7. **Test de Afinidad Pirata**:
   - Modal interactivo tipo quiz para descubrir qué miembro de la tripulación coincide con tu personalidad.

8. **Ambiente Acústico Marino**:
   - Control de audio para sintetizar el sonido de las olas del mar en tiempo real mediante AudioContext.

## 🚀 Instalación y Ejecución

Simplemente abre `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Edge, Brave, Safari). No requiere dependencias externas ni servidores Node.js.

```bash
# Clonar el repositorio
git clone <URL_DEL_REPOSITO>

# Abrir en el navegador
google-chrome index.html
```
